## 1. Skeleton

- `project.yml` (XcodeGen 2.46) generates `Apps/FlyCam.xcodeproj` (git-ignored in `Apps/.gitignore`, regenerated by every script).
- Targets: `DirectorCore` (macOS framework), `DirectorCoreTests` (unit tests), `DirectorApp` (macOS app),
  `director-cli` (macOS tool), `CaptureApp` (iOS app). Code in `Apps/Shared` is compiled into both
  DirectorCore and CaptureApp, so phone-side logic is tested on the Mac.
- Packages: `Packages/FlyCamKit` from track-l (local path), MetalSplatter 1.0.1 (vendored, see below).
- Scripts: `scripts/build_mac.sh`, `scripts/build_ios.sh` (generic/platform=iOS, `CODE_SIGNING_ALLOWED=NO`),
  `scripts/test_mac.sh`, `scripts/generate.sh`. Build output goes to `Apps/.build/`.

### Metal Toolchain missing (decision)

Xcode 27.2 on this Mac has no Metal Toolchain component, so no `.metal` file can be compiled at build time,
and installing it is not allowed for this track. Therefore:

- MetalSplatter 1.0.1 is vendored in `Apps/Vendor/MetalSplatter` with one patch: if there is no precompiled
  library, it compiles its unchanged shader sources at runtime (`Apps/Vendor/MetalSplatter/VENDORED.md`).
- DirectorCore's own shaders are Swift string constants compiled at runtime with `makeLibrary(source:)`.

With the toolchain installed, project.yml can point back at the upstream URL with `exactVersion: 1.0.1`.
